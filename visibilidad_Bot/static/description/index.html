Bot Visibility (Livechat)

In Odoo Community, chat bots appear for everyone. Want to limit your bot only to registered users or specific profiles? Take control with this module!

Universal (v17 & v18) Quick Installation

The Problem (Community)

By default, Odoo Community loads Livechat channels and bots (chatbots) for any website visitor. There is no native way to restrict the chat to only appear for employees, authenticated customers, or specific user profiles.

Our Solution

This module adds advanced visibility rules to Livechat channel configurations. You can choose exactly which type of users can see and interact with the bot, avoiding support saturation with unregistered or irrelevant visitor chats.

Key Features

Restricted Visibility

Hide the Livechat icon from anonymous visitors. Only logged-in users will be able to see and chat with the bot or agent.

Profile Filters

Do you want a bot exclusively for administrators or employees of a certain department? You can easily configure access groups.

Native Integration

Integrates directly into the standard Odoo Livechat channel view. No complex configurations or heavy dependencies.

Screenshots

Bot Visibility Options

Easily select who can see the chat button from the channel settings.

Bot Manager Dashboard

Manage all your bots and their specific restrictions from a centralized menu.

How does it work?

  • 1. Install the module in your Odoo database.
  • 2. Go to the Livechat app and select your channel or bot.
  • 3. You will see a new Visibility section. Select who can see the chat (e.g., Public, Authenticated Users, or a Specific Group).
  • 4. Save the changes and you're done! The bot will disappear for users who do not meet the rule.
